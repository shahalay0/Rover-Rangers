Put the dataset files here (they are not committed to GitHub):

- RML2016.10a_dict.pkl (641 MB):
  https://huggingface.co/datasets/FlowVortex/RML/resolve/main/RML2016.10a_dict.pkl?download=true
- GOLD_XYZ_OSC.0001_1024.hdf5 (21.4 GB, optional), needs `pip install h5py`:
  https://huggingface.co/datasets/FlowVortex/RML/resolve/main/GOLD_XYZ_OSC.0001_1024.hdf5?download=true
- SatNOGS recordings (README Part 3): put the observation's audio (.ogg) and, optionally, its decoded
  frames (.txt with hex lines) in data/satnogs/. Get them from https://network.satnogs.org
  (choose an AFSK 1k2 observation). Data is CC BY-SA 4.0, cite the observation ID.
